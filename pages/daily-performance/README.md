# 各部门业绩完成情况跟踪日报表平台

## 一、两种打开方式

### 方式1：双击 index.html（推荐，无需启动服务）
直接双击 `index.html` 即可在浏览器中打开使用，所有功能（导入 Excel、计算、导出图片）均可用。

### 方式2：双击「启动业绩平台.bat」（本地服务模式）
双击 `启动业绩平台.bat`，会自动打开浏览器访问 `http://localhost:8800/`。
关闭黑色命令行窗口即停止服务。

> 说明：也可以直接运行 `server.js`（用 Node 运行）手动启动服务。

## 二、日常使用流程

1. 打开平台（方式1 或 方式2）
2. 点「上传订单表」选择当日导出的「订单项目收退款表-明细-*.xlsx」
   - 默认勾选「合并到历史数据」：每日上传当天数据即可自动累计到月度（按收款单号分组替换，重复上传不重复计算）
3. 上传/编辑 VAB 会员表（可选，用于计算新增业绩）
   - 「👥 上传VAB会员表」导入 Excel，或点「📋 编辑会员」在线增删（每行一个会员号）
   - **会员列表自动保存在本机浏览器**（localStorage），下次打开自动恢复，无需重复导入
4. 报表自动结算当月累计与当日业绩（截止日期自动取最新一天）
5. 点「🖼 导出图片」导出日报表图片；「📥 导出Excel」导出表格

> ⚠️ 注意：VAB 会员保存在**浏览器本地**，请始终用**同一浏览器**（如 Google Chrome）打开平台；
> 建议用方式2（http://localhost:8800）访问，file:// 方式下 localStorage 可能受限。

## 三、功能说明

- **月目标**：可在「② 月目标（单位：万元）」中即时修改，实时影响报表；点面板标题可收起/展开
- **VAB 会员**：上传一次自动本地保存；「📋 编辑会员」可随时查看/增删会员号
- **每日累计**：上传当日订单表自动合并进月度数据（按收款单号分组替换）
- **每日列**：报表按"当月每个日期一列"展示（8/1 ~ 截止日）
- **截止日期**：可切换统计截止日期（默认自动取数据最新一天）
- **数据明细**：点「④ 业绩明细」可展开查看每个业务板块命中的数据行

## 四、目录结构

```
daily-performance/
├── index.html            # 主页面（双击即可用）
├── server.js             # 本地服务脚本（方式2用）
├── 启动业绩平台.bat       # 一键启动脚本（方式2）
├── assets/
│   ├── app.js            # 核心计算与渲染逻辑
│   ├── demo-data.js      # 内嵌示例数据（8月14日）
│   └── vendor/           # 离线依赖库（SheetJS / html2canvas）
└── sample/               # 示例数据 JSON（备用）
```

## 五、计算规则速览

| 板块 | 规则 |
|---|---|
| 品牌组-其他 | 营销部+品牌组+二级渠道∈{微信小程序,微信公众号,客服手机,前台座机,阿里(高德)} |
| 活动组-活动支持 | 营销部+活动组+活动支持 |
| 电商组 | 营销部+一级渠道∈{电商组,客户转介绍,企业团检} |
| 短视频组 | 营销部+短视频组 |
| 品牌组-自然到店 | 营销部+品牌组+二级渠道含"自然到店" |
| 商务部 | 渠道分类∈{商务部,市场部} |
| 合计 | 全部行现款支付 |
| 其他 | 合计 − 上述各板块 |
| 新增业绩 | 会员号在 VAB 列表中的行 |
| 基础业绩 | 合计 − 新增业绩 |
| 管家部 | 开单咨询师≠空/无/吴雅琴/许顺华/张帆 且渠道分类≠营销部 |
| 北郊 | 收款员工≠南媛 |
| 高新 | 合计 − 北郊 |
